## 重点新闻

### 1. 八个州起诉 OpenAI：聚焦“自主代理”的安全问题
*   **来源：** Planet AI Aggregate
*   **链接：** [Eight States Sue OpenAI: ChatGPT Safety and Rogue Agents](https://cellcog.ai/blog/eight-states-sue-openai/)
*   **发生了什么：** 10 月 14 日，美国八个州在各自法院对 OpenAI 提起诉讼。其中爱荷华州的起诉尤为激进，将 OpenAI 测试自主代理的行为视为“消费者欺诈”。
*   **为什么重要：** 这标志着监管机构开始关注 AI 代理（Agent）的自主性风险。对于训练师而言，这意味着未来的模型部署不仅要关注回答质量，还要严格限制模型的工具调用权限和自主决策范围，防止“越狱”或失控行为。
*   **初学者学习提示：** 学习如何设计“护栏”。在训练或微调阶段，不仅要教模型回答问题，还要教它识别何时应该拒绝执行某些操作。

### 2. Google DeepMind 与新加坡政府合作：端侧 AI 诈骗检测
*   **来源：** Google DeepMind Blog
*   **链接：** [Google DeepMind and Singapore Government collaborate to build fine-tuned AI model for scam detection](https://deepmind.google/blog/on-device-ai-scam-detection-mddi/)
*   **发生了什么：** Google DeepMind 与新加坡 GovTech 合作，开发了一种轻量级的端侧 AI 模型（基于 Gemma），用于在用户手机本地拦截对话式诈骗，且无需将数据上传至云端。
*   **为什么重要：** 展示了“端侧 AI”在隐私保护和实时响应方面的巨大优势。对于训练师，这是一个关于**模型压缩**和**隐私计算**的绝佳案例。
*   **初学者学习提示：** 关注模型大小与性能的权衡。了解如何通过量化或剪枝技术，将大模型部署在资源受限的设备上。

### 3. Ollama v0.40.5 发布：支持 Metal 自定义内核与工具调用
*   **来源：** Planet AI Aggregate
*   **链接：** [v0.40.5](https://github.com/ollama/ollama/releases/tag/v0.40.5-rc1)
*   **发生了什么：** 开源大模型运行框架 Ollama 发布了 v0.40.5 版本。主要更新包括将 Metal 自定义内核移植到 CUDA，改进模型推荐，并支持在历史记录中接受自定义工具调用。
*   **为什么重要：** Ollama 是本地部署大模型最流行的工具之一。此次更新增强了跨平台兼容性（特别是 Mac 用户），并改进了 Agent（代理）开发体验。
*   **初学者学习提示：** 这是一个动手实践的好机会。尝试使用 Ollama 运行一个本地模型，并编写简单的 Python 脚本测试其工具调用能力。

### 4. 新研究：新型图像模型更容易被“越狱”
*   **来源：** Planet AI Aggregate
*   **链接：** [RISE Study: Newer AI Image Models Easier to Jailbreak](https://cellcog.ai/blog/rise-image-model-jailbreak-study/)
*   **发生了什么：** 红队测试团队 White Circle 使用 RISE 方法发现，OpenAI 的 GPT Image 2.5 Flare 和 Google 的 Nano Banana 2.1 等新模型，比它们替换的旧模型更容易被攻击者绕过安全限制。
*   **为什么重要：** 随着模型能力的提升，安全边界往往会被压缩。这提醒训练师，模型越聪明，越需要严格的评估和对抗性测试。
*   **初学者学习提示：** 了解“越狱”攻击的基本原理。尝试构造看似无害但能诱导模型输出违规内容的提示词，这是安全训练的基础。

## 今日概念补充

### 1. 端侧 AI (On-Device AI)
指在用户设备（如手机、电脑）本地运行 AI 模型，而不是依赖云端服务器。这通常需要模型经过压缩和量化，牺牲部分精度以换取速度和隐私。

### 2. 越狱 (Jailbreak)
一种通过精心设计的提示词或攻击手段，诱导 AI 模型忽略其安全训练规则，输出原本被禁止的内容（如仇恨言论、非法指令）。

### 3. 代理 API (Agentic API)
一种允许 AI 模型不仅仅是回答文本，还能调用外部工具（如搜索、计算器、数据库）来执行任务的接口设计。

### 示例 2：Python 脚本测试 Ollama 工具调用
使用 Ollama 的 Python 库测试模型是否支持自定义工具调用（基于新闻中提到的 v0.40.5 更新）。

```python
import ollama

# 定义一个简单的工具
tools = [
  {
    'type': 'function',
    'function': {
      'name': 'get_weather',
      'description': '获取指定城市的天气信息',
      'parameters': {
        'type': 'object',
        'properties': {
          'city': {'type': 'string', 'description': '城市名称'},
          'unit': {'type': 'string', 'enum': ['celsius', 'fahrenheit']}
        },
        'required': ['city']
      }
    }
  }
]

# 调用模型
response = ollama.chat(
  model='llama3',
  messages=[{'role': 'user', 'content': '北京今天天气怎么样？'}],
  tools=tools
)

print("模型决定是否调用工具:", response['message']['tool_calls'])
```
