## 今日概念补充
- **提示工程**: 指的是为 AI 模型设计和优化输入提示的过程，以提高模型的响应质量。
- **循环工程**: 涉及在模型训练和推理过程中使用反馈循环来改进性能。
- **图工程**: 关注如何利用图结构来表示和处理数据，以提高模型的理解能力。

## 代码示例
以下是一个简单的 Python 片段，用于生成提示并调用 AI 模型：

```python
import openai

def generate_prompt(input_text):
    return f"请根据以下内容生成一个简要总结：{input_text}"

def call_ai_model(prompt):
    response = openai.ChatCompletion.create(
        model="gpt-5.6",
        messages=[{"role": "user", "content": prompt}]
    )
    return response['choices'][0]['message']['content']

input_text = "AI 技术的最新发展和应用"
prompt = generate_prompt(input_text)
summary = call_ai_model(prompt)
print(summary)
```
