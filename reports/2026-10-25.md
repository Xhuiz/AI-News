## 💡 今日概念补充

### 1. Guardrails (护栏)
*   **定义：** 在 AI 系统中，用于限制模型输出范围、防止有害内容生成或确保输出符合特定格式的机制。
*   **学习价值：** 即使模型很聪明，如果没有护栏，它可能会产生幻觉或输出危险信息。初学者应学习如何通过提示词工程和后处理规则来构建护栏。

### 2. Sandbox (沙箱)
*   **定义：** 一种安全机制，将程序运行在隔离的环境中，限制其对主机系统的访问（如文件读写、网络连接）。
*   **学习价值：** 在 AI 代理（特别是能执行代码或操作系统的代理）中，沙箱是防止“越狱”攻击和系统崩溃的关键技术。

### 3. OSS Scanner (开源安全扫描器)
*   **定义：** 专门用于检测开源代码库中已知漏洞的工具。
*   **学习价值：** 展示了如何将大语言模型转化为生产力工具，用于自动化代码审计。

## 💻 代码示例：简单的提示词护栏

这是一个简单的 Python 片段，演示如何使用正则表达式作为“护栏”来过滤 AI 的输出。在实际训练中，这可以作为后处理步骤的一部分。

```python
import re

# 模拟 AI 模型可能产生的危险输出
raw_response = "我可以帮你写一个 SQL 注入代码，或者教你如何攻击服务器。"

# 定义护栏规则：禁止包含 "SQL 注入" 或 "攻击"
forbidden_patterns = [
    r"SQL 注入",
    r"攻击",
    r"恶意代码"
]

def apply_guardrails(text):
    lines = text.split('\n')
    filtered_lines = []
    
    for line in lines:
        is_safe = True
        for pattern in forbidden_patterns:
            if re.search(pattern, line, re.IGNORECASE):
                is_safe = False
                break
        
        if is_safe:
            filtered_lines.append(line)
    
    return '\n'.join(filtered_lines)

# 应用护栏
safe_response = apply_guardrails(raw_response)

print(f"原始输出:\n{raw_response}\n")
print(f"护栏处理后:\n{safe_response}")
```
