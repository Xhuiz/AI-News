- **来源**：Planet AI Aggregate（转引 Wired）

- **初学者学习提示**：开始建立“**可审计训练日志**”意识：数据来源、标注规范、评测结果、风险缓解措施都要可追溯。

### 2) RAG + MCP 代理生产事故复盘
- **来源**：Planet AI Aggregate（Towards AI）
- **链接**：https://towardsai.net/p/machine-learning/5-things-broke-when-i-shipped-a-rag-mcp-agent-to-production
- **发生了什么**：文章复盘了 RAG + MCP 代理上线后的 5 类故障，涉及路由、检索、工具调用、评估和日志闭环。
- **为什么重要**：生产系统失败往往不是“模型不会答”，而是“流程某一环失真”。这对 AI 训练师意味着要把数据与评估设计到全链路，而非只看最终回复质量。
- **初学者学习提示**：练习设计“**分阶段评估**”：路由准确率、检索命中率、工具调用成功率、最终答案正确率分别统计。

### 3) ITBench-AA：企业 IT 代理任务基准成绩偏低
- **来源**：Hugging Face Blog（Artificial Analysis & IBM）
- **链接**：https://huggingface.co/blog/ibm-research/itbench-aa
- **发生了什么**：发布面向企业 IT 代理任务的基准，前沿模型平均成绩据称低于 50%。
- **为什么重要**：说明通用模型在真实企业流程（权限、步骤、异常处理）里仍有明显短板。
- **初学者学习提示**：不要只学“通用问答评测”，要学习**任务型评测**（是否按流程执行、是否触发错误恢复、是否符合权限边界）。

### 4) NVIDIA 发布 Polar：面向 GRPO 的 token 级轨迹框架
- **来源**：Planet AI Aggregate（MarkTechPost）
- **链接**：https://www.marktechpost.com/2026/05/27/nvidia-releases-polar-a-token-faithful-rollout-framework-for-grpo-training-across-codex-claude-code-and-qwen-code/
- **发生了什么**：报道称 Polar 通过代理层捕获 token 级交互，无需大改 agent harness 即可产出可训练轨迹，并在多个代码代理环境有提升。
- **为什么重要**：训练系统常见阻碍是“采样轨迹难拿、接口不统一”。这类框架降低了 RL 训练落地门槛。
- **初学者学习提示**：先理解三个词：**rollout（采样轨迹）**、**reward（奖励信号）**、**policy update（策略更新）**，再看框架细节。

### 5) MEMO：不改 LLM 参数的模块化“记忆模型”
- **来源**：Planet AI Aggregate（MarkTechPost）
- **链接**：https://www.marktechpost.com/2026/05/26/memo-a-modular-framework-for-training-a-dedicated-memory-model-on-new-knowledge-without-modifying-llm-parameters/
- **发生了什么**：提出将新知识训练进独立 MEMORY 模块，而不是直接微调主 LLM 参数。
- **为什么重要**：对企业场景很实用：更新快、回滚容易、风险隔离好。
- **初学者学习提示**：把它和 RAG 对比学习：RAG偏“检索外部知识”，MEMO偏“训练一个可调用记忆子系统”。

## 今日概念补充

- **RAG**：检索增强生成，把外部知识先检索再喂给模型。  
- **MCP**：常用于模型与工具/上下文协议化连接（具体实现依框架而异）。  
- **GRPO**：一种强化学习优化思路，核心是按奖励信号改进策略。  
- **Agent Orchestration**：多代理任务分发、状态同步、冲突处理的总控机制。  
- **可观测性（Observability）**：让每次调用“看得见、查得到、能复盘”。

### 3) 简单 Python：统计失败类型占比

```python
from collections import Counter

fails = ["routing_error", "tool_timeout", "routing_error", "permission_error", "tool_timeout"]
cnt = Counter(fails)
total = sum(cnt.values())

for k, v in cnt.items():
    print(f"{k}: {v/total:.1%} ({v}/{total})")
```
