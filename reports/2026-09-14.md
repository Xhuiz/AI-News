## 今日概念补充
- **对抗性奖励估计**: 通过对抗训练提升模型奖励预测的准确性，常用于强化学习。  
- **端侧语言模型（ODLM）**: 在本地设备运行的语言模型，无需云端依赖，适用于隐私敏感场景。  
- **多模态数据标注**: 结合文本、图像、音频等多种数据类型进行训练，提升模型泛化能力。

## 代码示例
```python
# LLM 评估指标模板（初学者可扩展）
def evaluate_llm_response(prompt, response, criteria):
    score = 0
    for key, value in criteria.items():
        if key in response:
            score += len(response.split(key)) * value
    return score

# 示例评估标准
criteria = {
    "准确性": 1,
    "完整性": 0.5,
    "逻辑性": 0.8
}

# 使用示例
prompt = "请解释 AI 安全的重要性"
response = "AI 安全非常重要，可以防止数据泄露和恶意使用，逻辑清晰且完整。"
print(evaluate_llm_response(prompt, response, criteria))
```
