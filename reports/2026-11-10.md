### 今日概念补充

**提示词工程（Prompt Engineering）**  
通过优化提示词提升模型输出质量。关键技巧包括：  
- 明确角色和权限（如“这是你的代码”）  
- 分解复杂任务为子步骤  
- 使用版本控制管理提示词  

**模型成本优化**  
- 利用缓存减少重复计算  
- 选择上下文窗口匹配任务规模（如 1M 上下文适用于代理任务）  
- 比较不同模型的成本效益比

### 代码示例

**提示词模板（代码生成任务）**  
```json
{
  "prompt": "作为资深软件工程师，优化以下代码结构，确保可维护性和性能。代码所有权归你，你决定如何重构。",
  "context": "现有代码片段...",
  "output_format": "JSON"
}
```

**数据标注 JSON（代理任务）**  
```json
{
  "task": "工具调用",
  "input": "用户请求...",
  "expected_output": {
    "tool": "browser_search",
    "parameters": {
      "query": "..."
    }
  }
}
```
