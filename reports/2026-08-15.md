## 今日概念补充

1.  **Agent (智能体)**：不仅仅是聊天机器人，而是能够感知环境、进行推理、使用工具并采取行动以实现特定目标的 AI 系统。
2.  **Watermark (水印)**：在 AI 生成的内容中嵌入不可见或微妙的信号，用于证明内容是由特定 AI 模型生成的，常用于版权保护和反欺诈。
3.  **Orchestration (编排)**：管理和协调多个 AI 模型或智能体，决定谁在何时执行什么任务，以及如何处理它们之间的通信。

## 代码示例：多智能体协作提示词模板

针对新闻中提到的多智能体系统，以下是一个简单的 Python 提示词模板示例，展示了如何定义不同的智能体角色以及它们之间的协作流程。

```python
# 多智能体系统提示词模板
MULTI_AGENT_PROMPT = """
你正在管理一个多智能体团队来完成一个复杂任务。请根据以下角色定义，分配任务并协调执行。

# 角色定义
1. **代码专家**:
   - 职责：负责编写、调试和优化代码。
   - 限制：必须使用最新的最佳实践，确保代码可读性。

2. **安全审计员**:
   - 职责：审查代码是否存在安全漏洞（如 SQL 注入、XSS）。
   - 限制：在代码执行前必须进行检查。

3. **文档撰写者**:
   - 职责：为代码编写清晰的注释和 README 文档。

# 协作流程
1. 代码专家首先生成初步代码。
2. 安全审计员审查代码，如果发现问题，返回给代码专家修改。
3. 审查通过后，文档撰写者生成文档。

# 当前任务
{TASK_DESCRIPTION}

请开始执行。
"""

# 模拟任务输入
current_task = "开发一个简单的用户登录 API 接口"

# 输出提示词
print(MULTI_AGENT_PROMPT.format(TASK_DESCRIPTION=current_task))
```

**学习点：** 这个模板展示了如何通过结构化的指令来模拟人类团队的分工。在实际训练中，你可以使用类似的模板来微调模型，使其具备多步骤推理和角色切换的能力。
