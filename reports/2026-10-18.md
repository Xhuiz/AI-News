## 今日概念补充

1.  **首 Token 延迟**: 指从用户发送请求到模型开始生成第一个字符所需的时间。对于代码补全、聊天机器人等场景，极低的延迟能显著提升用户体验。
2.  **物理 AI**: 指能够与物理世界交互的 AI 系统，通常涉及机器人技术、自动驾驶、工业自动化等，需要处理传感器数据、物理约束和实时控制。
3.  **PPO (Proximal Policy Optimization)**: 近端策略优化，一种广泛使用的强化学习算法，用于训练智能体在环境中做出决策以最大化奖励。
4.  **Bernard-Letac 构造**: 一种数学理论，用于将来自有偏置源头的重复采样转换为均匀分布的结果，常用于解决采样偏差问题。

### 示例 3：Python 片段 - 模拟 SAPO 的内存优化思路
虽然 SAPO 是一种算法，但其核心思想是减少单次 rollout 的计算量。以下是一个简单的 Python 片段，演示如何通过限制上下文长度来模拟内存优化。

```python
def optimize_context_window(model, prompt, max_tokens=512):
    """
    模拟限制上下文窗口以减少内存占用和首 Token 延迟。
    """
    if len(prompt) > max_tokens:
        # 截断提示词，保留关键信息（模拟 SAPO 的单次 rollout 逻辑）
        prompt = prompt[-max_tokens:] + "\n[Context truncated for efficiency]"
    
    # 模拟生成过程
    response = model.generate(prompt)
    return response

# 使用示例
user_input = "这是一个非常长的代码上下文..." * 100
optimized_response = optimize_context_window(claude_model, user_input)
print(optimized_response)
```
