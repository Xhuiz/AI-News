## 代码示例

以下是一个简单的Python代码片段，用于实现OCRmyPDF的基本功能：

```python
import subprocess

def convert_to_searchable_pdf(input_pdf, output_pdf):
    command = f"ocrmypdf {input_pdf} {output_pdf}"
    subprocess.run(command, shell=True)

# 示例用法
convert_to_searchable_pdf('scanned_document.pdf', 'searchable_document.pdf')
```
