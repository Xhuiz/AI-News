## 今日概念补充

### 1. 训练师（AI Trainer）
负责准备数据、设计提示、检查输出、制定评估标准的人。  
**重点**：不是只“喂数据”，而是让模型学会更稳定、更安全、更可用。

### 2. 评估标准（Evaluation Rubric）
一套判断模型回答好坏的规则，比如：是否正确、是否完整、是否安全、是否符合格式。  
**用途**：让标注和审核更一致。

### 3. 多模态（Multimodal）
模型同时处理文字、图片、音频、视频等多种输入。  
**训练提示**：不同模态的标注粒度常常不同，不能用同一套标准硬套。

### 4. 领域原理（Domain Principles）
某个专业领域的基础规律，比如化学反应规则、几何定理、代码规范。  
**训练提示**：高质量 AI 往往需要“通用能力 + 领域知识”一起学。

### 示例 3：简单 Python 统计标注一致率
```python
from collections import Counter

labels = ["正确", "正确", "部分正确", "正确", "错误"]
count = Counter(labels)

total = len(labels)
for k, v in count.items():
    print(k, round(v / total * 100, 1), "%")
```
