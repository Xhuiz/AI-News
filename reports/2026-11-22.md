## 重点新闻

### 1. OpenAI 发布对抗蒸馏防御策略
*   **来源：** OpenAI Blog
*   **链接：** [Combatting adversarial distillation](https://openai.com/index/combatting-adversarial-distillation)
*   **发生了什么：** OpenAI 宣布采用一种分层方法来应对对抗性蒸馏。这种方法结合了模型训练、安全防护、检测机制和执行手段，旨在防止攻击者通过特定的提示词或交互提取模型的底层能力。
*   **为什么重要：** 对于初学者来说，这是理解“模型安全”与“模型能力”边界的关键。对抗性蒸馏是黑帽攻击的一种，攻击者试图“教”模型教别人，从而窃取知识产权。了解防御机制有助于你在设计 AI 产品时建立安全护栏。
*   **初学者学习提示：** 关注“蒸馏”与“蒸馏攻击”的区别。蒸馏是正常的模型压缩技术，而对抗性蒸馏是利用蒸馏过程来反向推导模型参数的攻击手段。

### 2. MedChemBench：评估 AI 在药物发现中的推理能力
*   **来源：** OpenAI Blog
*   **链接：** [Can AI help scientists identify promising drug candidates?](https://openai.com/index/introducing-medchembench)
*   **发生了什么：** OpenAI 发布了 MedChemBench 数据集，用于评估 AI 模型在早期药物发现阶段的能力，包括分子结构解析、基于实验证据的推理以及化合物筛选。
*   **为什么重要：** 药物研发是 AI 的高价值应用场景。这个新闻展示了如何构建评估基准。作为训练师，你需要知道如何定义任务（如“筛选化合物”）并设计评估指标（如准确率、推理链质量）。
*   **初学者学习提示：** 学习如何构建垂直领域的评估基准。不要只看模型生成的最终答案，要看它的推理过程是否符合科学逻辑。

*   **初学者学习提示：** 理解“工具使用”在 Agent 架构中的核心地位。学习如何设计工具描述，使其能被模型准确检索和调用。

## 今日概念补充

### 对抗性蒸馏
*   **定义：** 一种攻击技术，攻击者通过精心设计的查询，诱导模型生成能够教给其他人的数据，从而反向推导出模型的内部参数或知识。
*   **学习价值：** 理解攻击者的思维有助于防御。防御策略通常包括：限制查询频率、添加噪声、使用蒸馏防御模型（即专门用来检测蒸馏攻击的模型）以及限制模型输出敏感信息。

### 工具检索
*   **定义：** 在 AI Agent 中，模型不再依赖静态的 API 列表，而是通过检索技术动态查找可用的工具或函数。
*   **学习价值：** 提升了系统的灵活性和可扩展性。训练师需要学习如何编写高质量的工具描述文档，以便模型能准确理解工具的输入输出格式。

## 代码示例

### 示例 1：评估 JSON 数据标注质量
在 MedChemBench 或类似任务中，我们需要评估模型生成的 JSON 是否符合结构化要求。以下是一个简单的 Python 片段，用于验证模型输出并计算“引用相关性”得分。

```python
import json

# 模拟模型输出
model_output = """
{
    "molecule": "Compound A",
    "rationale": "Based on the chemical structure, it resembles known inhibitors.",
    "citations": ["paper_1", "paper_2"]
}
"""

# 模拟预期的标准答案（用于评估）
ground_truth = {
    "molecule": "Compound A",
    "rationale": "High binding affinity predicted.",
    "citations": ["paper_1"]
}

def evaluate_json_output(output_str, gt):
    try:
        pred = json.loads(output_str)
        score = 0
        total_points = 0
        
        # 1. 结构完整性检查
        if "molecule" in pred and "rationale" in pred:
            score += 1
        
        # 2. 引用相关性检查
        if "citations" in pred:
            total_points += 1
            # 简单的交集计算
            if set(pred["citations"]) & set(gt["citations"]):
                score += 1
        
        return score, total_points
    except json.JSONDecodeError:
        return 0, 0

score, total = evaluate_json_output(model_output, ground_truth)
print(f"评估得分: {score}/{total}")
```

### 示例 2：Prompt 模板 - 模拟工具检索
针对 Google Gemini API 的工具检索功能，我们可以设计一个 Prompt 模板，引导模型先思考需要什么工具，再进行检索。

```markdown
# Role
你是一个专业的金融分析师助手。

# Task
用户正在询问关于某公司的财务状况。请按照以下步骤操作：

1. **分析意图**：用户需要什么信息？（例如：股价、财报、新闻）
2. **检索工具**：根据意图，决定调用哪个工具。
   - 如果需要股价，调用 `get_stock_price`。
   - 如果需要财报，调用 `get_financial_report`。
3. **执行与总结**：调用工具后，用中文总结结果。

# User Query
{user_query}

# Thought Process
1. 意图分析: {intent_analysis}
2. 选择工具: {selected_tool}
3. 执行结果: {tool_result}
```
