## 今日概念补充

### RLHF (Reinforcement Learning from Human Feedback)
**强化学习从人类反馈中学习**。这是一种训练 AI 模型的方法，不仅使用数据集进行监督学习，还通过人类对模型输出的打分（奖励/惩罚）来调整模型参数，使其行为更符合人类偏好。

### Digital Watermarking (数字水印)
一种嵌入在数字内容（如图像、文本、音频）中的信号，用于识别内容的来源或验证其真实性。在 AI 领域，水印通常用于证明内容是由特定模型生成的，或用于检测深度伪造内容。

## 代码示例

以下是一个简单的 Python 片段，模拟了 **多轮强化学习** 中的奖励函数设计。这是训练师在优化模型行为时最常用的工具之一。

```python
import json

def calculate_reward(model_response, user_query, history):
    """
    计算模型回答的奖励分数。
    包含基础分、安全性检查和上下文一致性检查。
    """
    reward = 0.0
    
    # 1. 基础分：回答长度适中
    if 20 <= len(model_response) <= 200:
        reward += 1.0
    else:
        reward -= 0.5

    # 2. 安全性检查 (模拟)
    harmful_keywords = ["暴力", "非法", "仇恨"]
    if any(keyword in model_response for keyword in harmful_keywords):
        reward -= 10.0  # 严重惩罚
        return reward, "Safety Violation"

    # 3. 上下文一致性检查 (模拟)
    # 检查回答是否与用户查询相关
    if user_query in model_response or model_response in user_query:
        reward += 2.0
    else:
        reward -= 1.0

    # 4. 多轮对话连贯性 (模拟)
    # 如果这是多轮对话，检查是否引用了上一轮的关键信息
    if len(history) > 0:
        last_turn = history[-1]
        if model_response in last_turn:
            reward += 1.0

    return reward, "Valid"

# 模拟使用场景
user_query = "如何使用 Python 优化数据库查询？"
model_response = "使用 Python 的 SQLAlchemy 库可以优化数据库查询。"
history = ["你有什么数据库优化的建议吗？"]

score, status = calculate_reward(model_response, user_query, history)
print(f"奖励分数: {score}, 状态: {status}")
```
