## 今日概念补充

**模型对齐（Model Alignment）**：确保 AI 模型的行为与人类意图一致，减少偏差和风险。  
**沙盒（Sandbox）**：在受控环境中测试 AI 模型，防止未预期行为。  
**多模态决策（Multimodal Decision）**：AI 模型结合文本、图像、音频等多种输入进行决策。

## 代码示例

### 提示词模板（Prompt Engineering）
```json
{
  "task": "决策任务",
  "input": {
    "text": "请选择以下选项中最合适的答案...",
    "images": ["image1.jpg", "image2.jpg"],
    "audio": "audio.wav"
  },
  "output_format": "JSON"
}
```

```json
{
  "data": [
    {
      "id": "task1",
      "input": {
        "text": "A cat is sleeping on the couch.",

      },
      "label": "cat"
    },
    {
      "id": "task2",
      "input": {
        "text": "A dog is running in the park.",
```
