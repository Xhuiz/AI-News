## 代码示例
以下是一个简单的 Python 片段，用于评估模型的准确率：

```python
from sklearn.metrics import accuracy_score

# 假设 y_true 是真实标签，y_pred 是模型预测的标签
y_true = [0, 1, 1, 0]
y_pred = [0, 1, 0, 0]

accuracy = accuracy_score(y_true, y_pred)
print(f"模型准确率: {accuracy:.2f}")
```
