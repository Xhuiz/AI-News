以下是一个简单的 Python 代码片段，展示如何使用 JSON 格式进行数据标注：

```python
import json

# 示例数据标注
data = {
    "image_id": "001",
    "annotations": [
        {
            "label": "spleen",
            "coordinates": {
                "x": 150,
                "y": 200,
                "width": 100,
                "height": 80
            }
        }
    ]
}

# 保存为 JSON 文件
with open('annotations.json', 'w') as json_file:
    json.dump(data, json_file)
```
