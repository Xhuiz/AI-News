## 今日概念补充

### 生存偏差（Survivorship Bias）

生存偏差是指在评估或分析时，只关注那些“存活”下来的对象或数据，而忽略了那些未能“存活”的对象或数据。在 AI 研究中，生存偏差可能导致对研究想法的评估不全面，因为已发表的论文往往只包含成功的研究想法。

### 提示词模板（Prompt Template）

```python
def generate_prompt(system_prompt, user_input):
    prompt = f"System: {system_prompt}\nUser: {user_input}\nAI:"
    return prompt

# 示例使用
system_prompt = "你是一个帮助用户解答问题的 AI 助手。"
user_input = "请告诉我如何学习 AI。"
prompt = generate_prompt(system_prompt, user_input)
print(prompt)
```
