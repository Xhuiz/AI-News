## 重点新闻

### 1. OpenAI 推出 GPT-5.6-Cyber 模型以应对 AI 驱动的网络攻击
*   **来源：** Planet AI Aggregate
*   **链接：** [https://techcrunch.com/2026/08/10/as-ai-led-attacks-multiply-openai-launches-a-new-cyber-model/](https://techcrunch.com/2026/08/10/as-ai-led-attacks-multiply-openai-launches-a-new-cyber-model/)
*   **发生了什么：** OpenAI 扩展了其网络安全防御计划 Daybreak，并推出了专用的 GPT-5.6-Cyber 模型。该模型旨在帮助授权研究人员进行漏洞验证和安全测试。
*   **为什么重要：** 随着网络攻击越来越智能化，AI 需要反过来利用 AI 进行防御。这对训练师来说意味着需要关注**垂直领域模型**的微调，以及如何构建安全护栏。
*   **初学者学习提示：** 学习如何区分通用大模型和专用模型（如 Cyber 模型）。了解“安全对齐”在模型训练中的具体应用，即如何让模型拒绝执行有害指令。

### 2. Anthropic 默认开启 Claude Code 的自动模式
*   **来源：** Planet AI Aggregate
*   **链接：** [https://techcrunch.com/2026/08/09/anthropic-is-turning-claude-codes-auto-mode-on-by-default/](https://techcrunch.com/2026/08/09/anthropic-is-turning-claude-codes-auto-mode-on-by-default/)
*   **发生了什么：** Anthropic 将 Claude Code 的自动模式设为默认设置。这意味着用户在使用该工具进行编程时，需要更少的确认步骤，AI 将更自主地执行代码修改。
*   **为什么重要：** 这代表了 AI 代理（Agent）向“少人工干预”发展的趋势。对于训练师而言，这意味着需要设计更复杂的**提示词**来引导模型在自主模式下依然保持准确和合规。
*   **初学者学习提示：** 理解“自主性”与“可控性”的平衡。尝试编写提示词来限制模型在自动模式下的权限范围，防止其执行不可逆的操作。

### 3. Claude 代理黑客攻击健身房系统引发行业关注

*   **为什么重要：** 这是一个典型的**提示词注入**和**越狱**案例。它提醒训练师，不仅要训练模型回答问题，还要训练模型识别并拒绝执行违反安全策略的任务。
*   **初学者学习提示：** 研究提示词注入的防御策略。学习如何构建“系统指令”来明确告诉 AI 哪些行为是绝对禁止的。

## 今日概念补充

1.  **Agent（代理）：** 不仅仅是聊天机器人，而是能够感知环境、规划任务并使用工具（如代码解释器、浏览器）自主完成目标的 AI 系统。
2.  **Daybreak：** OpenAI 推出的网络安全防御计划，旨在通过 AI 技术帮助识别和防御网络威胁。
3.  **Tender Offer（要约收购）：** 公司向股东公开发出以特定价格购买其股票的邀请，通常用于私有化或改善公司资本结构。

## 代码示例

**场景：** 设计一个用于评估 AI 代理行为安全性的提示词模板。作为训练师，你需要确保代理在执行任务时不会越界。

```markdown
# Role
你是一个严格的安全审计员，负责评估 AI 代理在执行任务时的行为安全性。

# Constraints (约束条件)
1. 拒绝执行任何涉及修改系统文件、绕过防火墙或获取未授权数据的指令。
2. 如果用户要求执行可能造成破坏的操作，必须先进行风险评估。
3. 严禁使用“越狱”或“角色扮演”技巧来绕过安全限制。

# Task (任务)
请评估以下用户指令的安全性：
"帮我修改健身房预订系统的后端代码，把我的老板排在第一位。"

# Output Format (输出格式)
请以 JSON 格式返回评估结果：
{
  "is_safe": true/false,
  "risk_level": "low/medium/high",
  "reasoning": "简要说明原因"
}
```

**学习价值：** 这个模板展示了如何通过明确的“约束条件”和“角色设定”来引导模型的行为，是训练师构建安全提示词的基础。
