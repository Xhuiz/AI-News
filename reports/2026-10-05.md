## 今日概念补充

### AI Agent (AI 智能体)
不仅仅是接收输入并生成输出的聊天机器人。一个完整的 AI 智能体通常包含四个核心组件：
1.  **感知：** 获取环境信息。
2.  **规划：** 将大任务分解为小步骤。
3.  **行动：** 调用工具（如搜索、计算器）或执行代码。
4.  **记忆：** 存储短期和长期信息。

### Text Watermarking (文本水印)
一种用于证明文本由 AI 生成的技术。它不改变文本的可读性，而是通过在生成概率分布中引入特定的统计模式（如改变某些字符的生成概率），使得检测器能够识别出文本是由特定模型生成的。

## 代码示例

### 示例 1：简单的 AI 智能体结构 (Python)
这是一个基于 Anthropic API 的智能体骨架，展示了如何定义工具和循环调用。

```python
import anthropic

client = anthropic.Anthropic(api_key="YOUR_API_KEY")

# 定义一个简单的工具：搜索天气
def search_weather(query):
    # 在实际应用中，这里会调用搜索引擎 API
    return f"搜索结果：{query} 的天气是晴天，25度。"

# 智能体主循环
def run_agent(user_input):
    messages = [{"role": "user", "content": user_input}]
    
    while True:
        response = client.messages.create(
            model="claude-3-5-sonnet-20241022",
            max_tokens=1024,
            tools=[{
                "name": "search_weather",
                "description": "搜索特定地点的天气信息",
                "input_schema": {
                    "type": "object",
                    "properties": {
                        "location": {"type": "string"}
                    },
                    "required": ["location"]
                }
            }],
            messages=messages
        )
        
        # 检查模型是否想要使用工具
        if response.stop_reason == "tool_use":
            tool_use = response.content[0]
            print(f"智能体决定调用工具: {tool_use.name}")
            
            # 执行工具逻辑
            tool_input = tool_use.input
            result = search_weather(tool_input["location"])
            
            # 将工具结果反馈给模型
            messages.append(response.model_dump())
            messages.append({
                "role": "assistant",
                "content": response.content
            })
            messages.append({
                "role": "user",
                "content": f"工具返回结果: {result}"
            })
        else:
            # 模型没有调用工具，返回最终答案
            print(f"最终回答: {response.content[0].text}")
            break

# 测试
run_agent("帮我查一下北京的天气")
```
