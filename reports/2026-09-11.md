## 今日概念补充

**工具使用数据生成（Tool Use Data Generation）**  
AI 代理需要通过工具（如搜索、计算）完成任务，高质量的工具使用数据是关键。ToolGrad 的 "先回答后生成" 模式通过验证 API 链路提升数据准确性，初学者可尝试模仿其逻辑设计数据集。

## 代码示例

### 提示词模板：金融数据摘要生成

```json
{
  "prompt": "根据以下财报数据，生成季度业绩摘要：营收增长 12%，净利润率 8.5%，应收账款周转天数 45 天。",
  "expected_output": "本季度营收增长 12%，净利润率提升至 8.5%，但应收账款周转天数延长至 45 天，需关注现金流风险。"
}
```

### 数据标注 JSON：ChatGPT for Financial Services

```json
{
  "data": [
    {
      "query": "计算 2025 年 Q2 的 EBITDA",
      "tool": "financial_data_api",
      "parameters": {"start_date": "2025-04-01", "end_date": "2025-06-30"},
      "response": "EBITDA 为 1.2 亿美元"
    }
  ],
  "annotations": {
    "tool_relevance": "高",
    "accuracy": "高"
  }
}
```
