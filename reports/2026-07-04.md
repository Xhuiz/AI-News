## 今日概念补充
- **多模态检索**: 指的是同时处理和检索多种类型的数据（如文本、图像、表格等）的能力，是当前 AI 研究的热点之一。
- **强化学习**: 一种机器学习方法，通过与环境的交互来学习如何做出决策，广泛应用于游戏、机器人等领域。

## 代码示例
以下是一个简单的 Python 代码片段，用于生成一个基本的 JSON 数据结构，适用于数据标注：

```python
import json

data = {
    "images": [
        {
            "file_name": "image1.jpg",
            "annotations": [
                {"label": "cat", "bbox": [100, 150, 200, 250]},
                {"label": "dog", "bbox": [300, 350, 400, 450]}
            ]
        }
    ]
}

with open('annotations.json', 'w') as json_file:
    json.dump(data, json_file, indent=4)
```
