## 今日概念补充
- **LoRA（Low-Rank Adaptation）**: 一种轻量级的模型适配技术，旨在减少训练时的计算资源消耗。
- **GRPO（Group Reinforcement Policy Optimization）**: 一种强化学习方法，通过群体样本生成来优化策略。

## 代码示例
以下是一个简单的 Python 片段，展示如何构建一个基本的提示词模板：

```python
def create_prompt(question, context):
    return f"请根据以下上下文回答问题：\n上下文：{context}\n问题：{question}\n回答："

# 示例使用
context = "人工智能是计算机科学的一个分支，旨在创建能够执行通常需要人类智能的任务的系统。"
question = "什么是人工智能？"
prompt = create_prompt(question, context)
print(prompt)
```
