## 今日概念补充

### 多智能体系统（Multi-Agent Systems）
- **定义**：多个智能体（如机器人、AI 模型）协同完成任务。
- **应用**：机器人编队、游戏 AI、物流调度。
- **学习价值**：理解分布式决策、协作机制。

### AI 伦理边界
- **核心问题**：AI 能力上限、责任归属、偏见风险。
- **实践建议**：设计可解释的 AI、保护用户数据、避免歧视性算法。

### 提示词模板（多智能体任务定义）
```json
{
  "prompt": "Agent A: {action1}, Agent B: {action2}, Goal: {shared_objective}",
  "agents": ["Agent A", "Agent B"],
  "constraints": ["no_conflict", "max_steps=10"]
}
```

### 数据标注 JSON（多智能体协作任务）
```json
{
  "data": [
```
