## 今日概念补充

### 代理（Proxy）
代理是一种中间服务器，用于转发请求和响应，常用于解决 API 兼容性问题。例如，将 Claude Code 的 Messages API 转换为 OpenAI 的 chat-completions 格式。

### 预训练（Pretraining）
预训练是指在大规模数据上训练模型，使其具备通用能力。例如，OpenAI 的 Bel 模型据称是 10 万亿参数的预训练模型。

### 提示工程（Prompt Engineering）
提示工程是指设计输入文本以优化模型输出的技术。例如，GPT-6 指南中提到的“推理优化”和“提示工程”。
