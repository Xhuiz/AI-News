### 1) MEMO：不改 LLM 参数的“外置记忆”训练框架
- **来源**：Planet AI Aggregate（转引 MarkTechPost）
- **链接**：https://www.marktechpost.com/2026/05/26/memo-a-modular-framework-for-training-a-dedicated-memory-model-on-new-knowledge-without-modifying-llm-parameters/
- **发生了什么**：NUS、MIT、A*STAR 研究者提出 MEMO，将新知识编码到独立可训练的 MEMORY 模块，而不是直接微调主 LLM。

## 今日概念补充

- **Speculative Decoding（推测解码）**：先由小模型生成候选，再由大模型验证，目标是提速降本。  
- **Attention Drift（注意力漂移）**：长序列或复杂推理中，模型关注点偏移导致输出不稳定。  
- **Agentic AI（代理式 AI）**：模型不只“回答”，还能“规划-调用工具-执行-复盘”。  
- **Observability（可观测性）**：记录链路、日志、指标、追踪，便于定位错误与审计。  
- **Guardrails（护栏）**：对预算、权限、内容安全等设置强约束，避免高风险行为。

### 1) 提示词模板：让智能体输出“可评估”结果
```text
你是运维巡检助手。请基于输入的监控事件，输出 JSON：
{
  "summary": "一句话概览",

要求：

  },

  },

    "actionability": 0.4,
    "clarity": 0.2
  }

### 3) 简单 Python：批量计算评估分（示例）
```python
samples = [
    {"factuality": 0.9, "actionability": 0.8, "clarity": 0.7},
    {"factuality": 0.7, "actionability": 0.6, "clarity": 0.9},
]
weights = {"factuality": 0.4, "actionability": 0.4, "clarity": 0.2}

def score(x):
    return sum(x[k] * w for k, w in weights.items())

avg = sum(score(s) for s in samples) / len(samples)
print(f"average_score={avg:.3f}")
```
