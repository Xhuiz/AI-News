## 今日概念补充

- **多代理系统**: 指多个智能代理协同工作以完成复杂任务的系统。理解其架构和应用对AI训练师至关重要。

## 代码示例

以下是一个简单的Python片段，用于创建一个多代理系统的基本框架：

```python
class Agent:
    def __init__(self, name):
        self.name = name

    def act(self):
        return f"{self.name} is acting."

class MultiAgentSystem:
    def __init__(self):
        self.agents = []

    def add_agent(self, agent):
        self.agents.append(agent)

    def run(self):
        for agent in self.agents:
            print(agent.act())

# 示例使用
mas = MultiAgentSystem()
mas.add_agent(Agent("Agent1"))
mas.add_agent(Agent("Agent2"))
mas.run()
```
