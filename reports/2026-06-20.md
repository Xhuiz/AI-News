## 今日概念补充
- **零拷贝（Zero-Copy）：** 一种数据传输技术，允许数据在内存中直接访问，减少了数据拷贝的开销，提高了性能。
- **模型压缩（Model Compression）：** 通过减少模型的参数数量或复杂度来降低模型的计算需求和存储需求。

import json

# 示例数据标注

}

# 将数据保存为 JSON 文件
