## 今日概念补充

- **持续强化学习**: 一种机器学习方法，模型在不断变化的环境中进行学习，而不是在固定的环境中进行训练。
- **低代码/无代码平台**: 允许用户通过图形界面而非编程代码来创建应用程序的工具，降低了技术门槛。

## 代码示例

以下是一个简单的Python片段，用于创建一个基本的JSON数据标注格式，适用于AI训练数据：

```python
import json

data = {
    "annotations": [
        {
            "image_id": "001",
            "label": "cat",
            "bbox": [100, 150, 200, 250]
        },
        {
            "image_id": "002",
            "label": "dog",
            "bbox": [50, 75, 150, 200]
        }
    ]
}

with open('annotations.json', 'w') as json_file:
    json.dump(data, json_file, indent=4)
```
