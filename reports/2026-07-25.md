## 今日概念补充
- **提示缓存**: 提示缓存是一种优化技术，通过存储先前的输入和输出，减少重复计算，从而提高响应速度和降低成本。
- **语言模型幻觉**: 指模型生成的内容与事实不符的现象，评估和理解这种现象对于提升模型的可靠性至关重要。

## 代码示例
以下是一个简单的 Python 片段，用于实现提示缓存：

```python
class PromptCache:
    def __init__(self):
        self.cache = {}

    def get_response(self, prompt):
        if prompt in self.cache:
            return self.cache[prompt]
        else:
            response = self.call_model(prompt)  # 假设这是调用模型的函数
            self.cache[prompt] = response
            return response

    def call_model(self, prompt):
        # 模拟模型调用
        return f"Response for: {prompt}"

# 使用示例
cache = PromptCache()
print(cache.get_response("Hello, AI!"))
print(cache.get_response("Hello, AI!"))  # 第二次调用将从缓存中获取
```
